# Environment Variables

All configuration is driven by `.env`. Copy `.env.example` to `.env` and fill any required secrets. No real secrets are committed.

## Core application

| Variable | Required | Example | Sensitive | Notes |
|---|---|---|---|---|
| `APP_NAME` | Yes | `RankBeacon` | No | Display name |
| `APP_ENV` | Yes | `local` | No | `local`, `production`, `testing` |
| `APP_KEY` | Yes | `base64:...` | **Yes** | Generated by `php artisan key:generate` |
| `APP_DEBUG` | Yes | `true` | No | Disable in production |
| `APP_URL` | Yes | `http://localhost:8000` | No | Used for URL generation |
| `APP_TIMEZONE` | Yes | `UTC` | No | Explicitly set to UTC |

## Database

| Variable | Required | Example | Sensitive | Notes |
|---|---|---|---|---|
| `DB_CONNECTION` | Yes | `sqlite` / `mysql` | No | SQLite for dev, MySQL for prod |
| `DB_HOST` | For MySQL | `127.0.0.1` | No | |
| `DB_PORT` | For MySQL | `3306` | No | |
| `DB_DATABASE` | For MySQL | `rankbeacon` | No | |
| `DB_USERNAME` | For MySQL | `rankbeacon` | No | |
| `DB_PASSWORD` | For MySQL | `secret` | **Yes** | |

## Cache, session, queue

| Variable | Required | Example | Sensitive | Notes |
|---|---|---|---|---|
| `CACHE_STORE` | Yes | `database` / `redis` | No | |
| `SESSION_DRIVER` | Yes | `database` | No | |
| `QUEUE_CONNECTION` | Yes | `database` | No | |

## Other

| Variable | Required | Example | Sensitive | Notes |
|---|---|---|---|---|
| `MAIL_MAILER` | Yes | `log` | No | |
| `BROADCAST_CONNECTION` | Yes | `log` | No | |
| `VITE_APP_NAME` | Yes | `${APP_NAME}` | No | Exposed to Vite build |

Sensitive values (`APP_KEY`, `DB_PASSWORD`, `AWS_*`, `REDIS_PASSWORD`) must never be committed.
