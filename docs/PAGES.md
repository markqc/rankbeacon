## Home page structure (`/`)

1. **Shared header** — `Header` with lighthouse mark, descriptor, primary nav, mobile menu, and `Explore Tools` CTA.
2. **Hero** — eyebrow `SEO clarity, one tool at a time.`, heading `See how your pages appear in search.`, supporting message for marketers/developers/business owners, primary CTA `Open SERP Preview`, secondary CTA `Explore All Tools`, and an original HTML/CSS SERP preview visual.
3. **Benefit strip** — `No account required`, `Instant live preview`, `Desktop and mobile`.
4. **Tools grid** — Google SERP Preview marked `Available` with a working link; Meta Tag Checker, Robots.txt Tester, and Open Graph Preview marked `Coming soon` and not presented as links.
5. **How it works** — three steps: enter URL, edit title/description, compare desktop and mobile.
6. **Final CTA** — `Open SERP Preview` and `Explore All Tools`.
7. **Shared footer** — dynamic year credit: `© [year] Authority Lighthouse. Platform developed by MCaneda.com.`

## SEO / metadata

- `<title>`: generated by `PageHead`/`MainLayout` and the Inertia `createInertiaApp` title formatter.
- Meta description and Open Graph description are set in `Home.tsx`.
- Canonical URL is built from the shared `app.url` Inertia prop.
- Structured data (`application/ld+json`) includes `Organization` and `WebSite` schema.

## Future-edit guidance

- Change the hero copy, CTAs, or audience list in `resources/js/pages/Home.tsx`.
- Add or remove tools from the `tools` array in `Home.tsx`. Keep `status: 'available'` only for ready tools.
- Update the meta description and `jsonLd` object when messaging or organization details change.
- Add an `ogImage` prop to `MainLayout` once brand social-share imagery is created.
- New content pages should extend `MainLayout` and use `SectionHeading`, `Container`, and `Card`.
